# Phase 5 P1：局部信用分配（v0.16.0）结果

- 日期：2026-10-23
- 预注册：`HANDOFF.md` §6N；参数变更记录：`docs/parameter_policy.md`
- 唯一改动：三因子调制由全局标量 `D(t)` 改为**池特异** `D_up/D_down`
  - 命中：`D_up = D_down = +1`
  - 未命中：按 impact 前一刻的 `ball_y − paddle_y` 符号，
    球在上方 → `D_up=+1, D_down=−1`；球在下方 → `D_up=−1, D_down=+1`
  - 幅度沿用 `reward_plus/reward_minus=±1`；STDP、资格迹、稳态、读出全部冻结
- 条件：`local_3b`、`local_3b_no_hs`、`local_3b_play_hs`、`static`、`3b`（全局对照）
- 规模：5 条件 × 15 seeds × 600 s，2 细胞，ball 0.5，gain 0.15，4–40 Hz，背景噪声关闭
- 统计：两组置换检验（20,000 次，双侧）

## 0. 一次对照污染及其修复（必须先说明）

首次运行用命令行开关 `--local-credit` 打开局部信用，而该开关作用于**整批条件**，
使 `3b` 全局对照臂也拿到了池特异 `D`，于是 `local_3b` 与 `3b` 逐位相同
（rally 0.151、`w_diff corr` 0.364 完全一致），对照失效。

修复：信用分配改为**由条件名决定**（含 `local` 才启用），移除全局开关，
并新增 local 相关的置换检验对照。受污染批次存档于
`results/phase5_local_credit_600_bug_globalflag/`，不参与任何推断。
下表全部来自修复后的干净批次。

## 4. 预注册假设判定

| 假设 | 判定 |
|---|---|
| H1：local_no_hs / local_play_hs 的 `w_diff corr > 0.3`，global ≈ 0 | **支持**：0.780 / 0.426 vs 全局 0.000 |
| H2：local 条件行为高于 static；no_hs/play_hs 不因稳态饱和退化 | **不支持**：no_hs 0.220 vs static 0.204（p=0.512），play_hs 0.164 < static（p=0.054） |
| H3：global_3b 无学习收益（对照） | **支持**：0.151，显著低于 static（p=0.013），梯度归零 |
| H4：若 local_no_hs 仍无行为增益（尽管梯度存在）→ 信用分配不是唯一瓶颈，停止局部信用线 | **触发**：梯度成立但行为仅与 static 持平 |

## 5. 机制解读

1. **信用分配确实是一个真实瓶颈，但不是唯一瓶颈。**
   把全局标量换成按球侧反号的局部 D，足以让两池权重分化出正确符号的 y 梯度
   （0.000 → 0.780，impact corr 0.18 → 0.74），并且显著优于全局臂（p=0.014）。
   这修正了“局部调质完全无效”的先前判断。
2. **但梯度强度有上限，行为不越过手工结构。**
   no_hs 的 `w_diff corr` 0.780、`impact corr` 0.735 仍低于 static 的 1.000/0.920；
   行为 +0.015（p=0.512）。说明在这个 2 细胞系统里，**读出结构的先验权重
   比可塑性学到的权重更有效**，可塑性最多把结构“恢复”到接近 static，而不能超过它。
3. **稳态仍是压倒性的破坏者。**
   `local_3b`：稳态把 40% 权重推到 `w_max`，梯度只剩 0.364，行为 0.151，
   甚至不如全局臂的对照水平（同一数值，但梯度被结构性抹平）；
   `play_hs` 只把 `w_max` 比例从 0.40 降到 0.35，仍不足以保梯度。
   只要目标是固定的 20 Hz、而游戏期平均率远低于它，乘性上调就会持续压过 STDP。
4. **两池共活动仍未破解。** exclusive 仅 0.031（no_hs），率相关 0.950；
   局部 D 改善了权重符号，但没有产生真正的运动竞争。

## 6. 结论

- **正结果**：池特异性信用分配能让极小网络在闭环中形成正确方向的输入-输出梯度，
  这是此前全局三因子做不到的。
- **负结果（预注册停止）**：该梯度不足以带来超过手工 push-pull 结构的行为增益；
  在固定 20 Hz 稳态目标下，梯度还会被饱和抹平。
- 按 §6N 停止规则，**局部信用线到此为止**：不调 D 的幅度、不叠加新的局部规则。
- 结论句：*“在 2 细胞 push-pull 网络中，局部信用分配解决了梯度的符号问题，
  但行为上限由读出结构与稳态目标决定；仅靠局部调制无法突破这一上限。”*

## 7. 限制

- 只测了一种局部规则（Miss 时按球侧 ±1），未测连续误差或仅惩罚单侧。
- 未做 T1/T2 分段比较（本流水线只输出全程汇总）。
- `local_3b` 与全局 `3b` 的 rally 数值相同属巧合（不同权重轨迹、不同动作序列），
  不作为“局部无效”的证据；梯度指标才是该对比的判据。
- 跨臂 RNG 流不共享，置换检验为描述性，未做多重比较校正。
