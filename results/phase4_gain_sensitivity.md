## 4. 预注册假设的判定

| 假设 | 内容 | 判定 |
|---|---|---|
| H1 | `pushpull_static` 的 rally / 命中率随 gain 单调上升 | **不支持**：rally 0.214 → 0.201 → 0.246；hit 0.168 → 0.151 → 0.180。impact error 确实单调下降（1.84 → 1.64 → 1.32），但没有转化为命中率。 |
| H2 | `symmetric_static` 在所有 gain 下保持 ~0.1 | **支持**：三个剂量点完全相同的 0.1056（差分恒 0，gain 乘 0 仍为 0）。 |
| H3 | 若可塑性收益被增益掩盖，3b/no_hs 在高 gain 下应超过 static | **不支持**：no_hs 与 static 持平（0.30：+0.003，p=0.974；0.60：−0.010，p=0.897）；3b 在高 gain 下反而显著更差（−0.152，p=0.010）。 |
| H4 | 稳态仍使两池权重饱和趋同，与 gain 无关 | **支持**：3b 的 `frac at w_max` 为 0.175 → 0.275 → 0.325，`mean|w_up−w_down|` = 0.000，读出斜率约 0.77 Hz/bin；play_hs 的梯度相关为 −0.056/−0.077。 |

## 5. 机制解释

1. **K_eff 不随 gain 缩放**。`velocity_gain` 从 0.15 变到 0.60（×4），
   但 play 期速度–误差回归斜率始终 ≈ 0.20 /s。原因不是执行器没变快（play |v| 从 0.179 升到 0.595），
   而是差分率本身被 ball_x 门控：感觉率因子随球接近从 4 Hz 升到 40 Hz，
   控制信号在回合后段才变大。线性回归被“晚段大信号 + 到球后过冲”主导，
   不能把增益变化读成比例控制增益。
2. **提高 gain 改善的是末端误差，不是命中率**。
   static 的 impact error 从 1.84 降到 1.32，但命中要求 |error| ≤ 0.5；
   初始误差大多在 1.5–3.5 bins，末端仍有 1.3 bins，命中率自然停在 0.18 左右。
3. **高 gain 放大随机策略的伤害**。random paddle 的 rally 从 0.141 降到 0.094，
   因为随机速度幅度随 gain 增大；因此 static − random 的对比在高 gain 下反而显著（p=0.009）。
   这说明结构优势是真的，但绝对表现被“信息到达太晚 + 回合太短”限制。
4. **可塑性仍未获益**。no_hs 与 static 在三个 gain 下都持平；
   3b 因为稳态抹掉了差分编码（斜率 0.77），高 gain 只是把噪声放大，行为更差。
5. **对称对照是干净的零**。三个 gain 下完全相同的 0.1056，验证了读出结构是行为的必要条件。

## 6. 结论

- **“行为瓶颈是一个可调的标量增益”这个假设被否定。** 把 `velocity_gain` 翻倍到 0.30 没有改善，
  四倍到 0.60 只带来很小的末端误差改善和 ±0.03 的 rally 变化。
- 更准确的表述是：瓶颈在**读出信号的时间形状**——感觉率随 ball_x 从 4 Hz 升到 40 Hz，
  加上 300 ms 读出窗口和 2 s 回合，使控制信息集中在末端；
  单纯提高增益只会让末端响应更大，不能把“晚到的信息”变成“早到的信息”。
- 结构读出（push-pull）与对称对照的差异在高 gain 下更清楚，但它不足以单独解决任务。
- 可塑性（STDP/三因子/稳态）在三个 gain 下都没有可靠收益；稳态的饱和效应与 gain 无关。
- **不再追加 gain 剂量点，也不再用 gain 调成绩。** 下一步应改“信息时间形状”（背景噪声、读出归一化/预测、
  更长回合或更慢球），或进入 3–5 细胞测分化；这些都属于新版本，需重新预注册。

## 7. 限制

- 每条件 15 seeds × 120 s，但每 seed 只有 ~12 个 rally；行为指标的置信区间很宽。
- 跨 gain 比较是描述性的：同一 seed 的闭环轨迹在不同 gain 下发散，不能做严格的同分布配对；
  同 gain 内也使用两组（非配对）置换检验，因为各条件的 RNG 流不共享。
- 未做多重比较校正；六个对比中 p=0.009/0.008/0.018/0.020 应视为探索性证据。
- `K_eff` 是线性回归摘要，不是控制系统的频率响应；它在这里用于说明“gain 没有按比例转化为闭环增益”。
