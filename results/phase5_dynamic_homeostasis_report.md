# Phase 5 P2：动态稳态目标带（v0.17.0）结果

- 日期：2026-10-23
- 预注册：`HANDOFF.md` §6O；参数变更记录：`docs/parameter_policy.md`
- 唯一改动：稳态目标由 20 Hz 点改为功能带 `[5, 30] Hz`，带内不缩放，且只在 play 期应用
  - `r < 5`：`w ← w·(5/r)^α`；`5 ≤ r ≤ 30`：不缩放；`r > 30`：`w ← w·(30/r)^α`
  - α=0.05、每秒一次、`w_min/w_max`、300 ms 速率窗口全部冻结
- 条件：`local_3b_dyn`（局部 D + 动态带）、`dyn_3b`（全局 D + 动态带）、
  `local_3b_no_hs`（无稳态）、`static`（手工结构上限）、`3b`（固定 20 Hz 基线）
- 规模：5 条件 × 15 seeds × 600 s，2 细胞，ball 0.5，gain 0.15，4–40 Hz，背景噪声关闭
- 统计：两组置换检验（20,000 次，双侧）

## 4. 预注册假设判定

| 假设 | 判定 |
|---|---|
| H1：local_dyn 的 at w_max ≤ 0.10、w_diff corr > 0.5，且 play 期率 10–25 Hz | **不支持**：at w_max 0.25/0.29；corr 0.498（差 0.002）；play 每池 ≈16.9 Hz 在带内 |
| H2：local_dyn 行为 ≥ no_hs 且 ≥ static | **不支持**：0.196 < 0.220（p=0.334）且 < 0.204（p=0.643） |
| H3：若 dyn ≈ no_hs 且都不超过 static → 饱和不是剩余瓶颈 | **支持**：三者统计上同档，均未超过 static |
| H4：若 dyn 显著低于 no_hs → 停止动态带 | **未触发**（p=0.334），但 H1 已失败 |

**停止规则执行**：H1 不成立 → 动态稳态带线到此为止，不调 5/30 Hz 边界、不调 α。

## 5. 机制解读

1. **为什么 band 内不缩放，权重仍会饱和？**
   稳态速率来自 300 ms 窗口（`readout_window_ms`）。每池在 play 期约 17 Hz，
   300 ms 内平均只有 ≈5 个 spike；Poisson 波动使不少秒的窗口率掉到 5 Hz 以下
   （例如 1 个 spike = 3.3 Hz），触发 `(5/3.3)^0.05 ≈ 1.026/s` 的上调。
   600 次缩放累积后仍会把 25–29% 权重推到 `w_max`。
   这不是边界选错，而是**短窗口率估计器的方差**与乘性控制叠加的结构性问题。
2. **降低饱和 ≠ 形成梯度。**
   `dyn_3b` 的 at w_max 从 0.34 降到 0.14、impact corr 几乎翻倍，
   但 `w_diff corr` 仍是 0.000：全局标量 D 对两池完全同号，
   饱和只是抹平梯度的“放大器”，不是梯度缺失的根因。
   这独立复现了 P1 的核心结论。
3. **即使完全不饱和，行为也不再上升。**
   `local_no_hs` 梯度 0.780、权重未饱和，rally 仍与 static 持平（p=0.516）。
   动态带只是把系统从“被稳态破坏”拉回“接近结构先验”，
   但没有越过 static 的天花板。
4. **行为上限因此不在稳态。** 剩余瓶颈更可能是：
   控制信息集中在回合末端（信息晚到）、两池共活动（exclusive ≤ 0.031）、
   以及 2 细胞网络缺乏群体动力学。

## 6. 结论

- **弱正结果**：功能带目标能实质减轻饱和（at w_max 0.34→0.14，impact corr 0.18→0.38），
  方向与生理稳态的“功能范围”解释一致。
- **核心负结果**：减轻饱和既不产生梯度（全局 D），也不把行为推过 static（局部 D）。
- **H4/H3 合起来说明**：饱和、信用分配都已分别被处理过，行为天花板仍由
  读出结构与时间编码决定；继续在稳态参数上微调没有科学收益。
- 按 §6O 停止规则，**动态稳态带线到此为止**。
- 下一步建议：转向**时间维度**（短时程突触可塑性 / 预测性前馈读出），
  或直接进入**更大网络**（10 细胞 E/I）；两者都需要新的预注册。

## 7. 限制

- 只测了一个带 `[5, 30]` Hz 与 α=0.05；未测其他边界（按停止规则也不再试）。
- 速率仍用 300 ms 窗口估计；更长的稳态窗口可能减轻方差，但这属于新机制，未预注册。
- 跨臂（固定点目标 vs 动态带）RNG 流不同，比较为描述性。
- 未做 T1/T2 分段；本流水线只输出全程汇总。
