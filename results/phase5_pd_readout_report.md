# Phase 5 P5：PD 读出（v0.20.0）结果

- 日期：2026-10-23
- 预注册：`HANDOFF.md` §6R；参数变更记录：`docs/parameter_policy.md`
- 唯一改动：读出由比例控制改为 PD
  - `v = clip(Kp·Δr + Kp·τ_pred·dΔr/dt, ±v_max)`，`Kp=0.15`，`τ_pred=50 ms`
  - 微分用平滑率差的 tick 差分，再经同一 α=0.2 低通；rest 期照常更新状态
  - 细胞、突触、可塑性、稳态、STP 全部冻结
- 条件：`local_no_hs_pd`、`local_no_hs`、`static_pd`、`static`
- 规模：4 条件 × 15 seeds × 600 s，2 细胞，ball 0.5，gain 0.15，4–40 Hz

## 4. 预注册假设判定

| 假设 | 判定 |
|---|---|
| H1：local_pd 高于 local_no_hs ≥+0.02 且 p<0.05 | **不支持**：0.000（p=0.998） |
| H2：static_pd 高于 static ≥+0.02 且 p<0.05 | **不支持**：+0.005（p=0.722） |
| H3：local_pd 高于 static ≥+0.02 | **不支持**：+0.015（p=0.501） |
| H4：H1 与 H2 都不成立 → PD 不是杠杆，停止接口线 | **触发** |

**停止规则执行**：不调 τ_pred、不调 Kd；接口线到此为止。

## 5. 机制解读

1. **τ_pred=50 ms 只能补偿几十毫秒的环路延迟，而信息晚到是 2 s 量级。**
   感觉率被 ball_x 门控，控制信息在回合末端才出现；微分项只能给出约 50 ms 的提前量，
   对于“等球靠近才看得清 y”这一结构性延迟无能为力。
2. **平滑把微分吃掉了。** 率差本身已经过 α=0.2（有效 τ≈45 ms）的低通，
   再做一次同样的低通，导数幅度很小：mean |v| 0.28→0.28、0.18→0.19。
   这不是实现错误，而是预注册参数下的真实效果。
3. **PD 不改变闭环结构。** 两臂的 rate up/down、exclusive、共活动全部不变；
   PD 只在动作层加了一个小偏置，没有引入新的信息通路。
4. **对用户建议的校正**：PD 是“低成本的接口检验”，结果证明它**不是**行为杠杆；
   真正要解决信息晚到，需要改变编码（相位/延迟编码）或改变控制对象（预测球的位置），
   或换任务（连续追踪），而不是在读出端加微分。

## 6. 结论

- **负结果**：PD 读出在预注册参数下对行为无影响（p=0.998 / 0.722），
  对读出相关性只有 +0.01 量级的提升。
- 按 §6R 的 H4，**接口/PD 线停止**。
- 项目总状态不变：2–10 细胞 + 局部可塑性 + 率解码的行为上限由
  **编码的信息到达时刻与执行器增益**决定；接口层的线性补偿无法突破。

## 7. 限制

- 只测了一个 τ_pred=50 ms（按停止规则不再试其他值）。
- 微分基于 300 ms 窗口率，未使用脉冲级时序；脉冲级 PD 属于新编码，不在本版本。
- 未与 STP、10 细胞网络组合（避免多改动混杂）。
